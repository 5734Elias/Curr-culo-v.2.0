# Skill: accessibility-review

Esta skill define as regras de acessibilidade WCAG 2.2 nível AA no frontend.

## Diretrizes de Execução
1. **Teclado:** Todo o site público e administrativo deve ser navegável por teclado (`Tab`, `Enter`, `Space`, `Escape`).
2. **Focus Management:** Modais devem possuir focus trap e restaurar o foco ao fechar.
3. **Semântica HTML:** Usar tags HTML5 estruturais (`<main>`, `<section>`, `<nav>`, `<article>`, `<header>`, `<footer>`).
4. **Contraste:** Garantir contraste de cores de no mínimo 4.5:1 para texto normal e 3:1 para texto grande.
