# Aplicação Frontend — Portfólio Profissional v3.0

Esta pasta contém o código-fonte da aplicação web em Next.js 16 (App Router), React 19 e Tailwind CSS 4.

---

## 🚀 Comandos Rápidos

```bash
# Instalar dependências
npm ci

# Iniciar servidor de desenvolvimento
npm run dev

# Executar validação estática de tipos
npm run typecheck

# Executar ESLint
npm run lint

# Executar suíte quíntupla de testes automatizados
npm run test

# Compilar para produção
npm run build
```

Para a documentação completa de arquitetura, segurança e testes, consulte o diretório [`../../docs/`](../../docs/) na raiz do projeto.
